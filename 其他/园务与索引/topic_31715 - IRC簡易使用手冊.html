注意：參觀和練習時的禮儀

請勿在正在跑團的頻道中發言或是試用任何功能，例如投骰。如果你無法確定該頻道是否在跑團，請等待5分鐘時間，如果沒有任何發言，或是里面明显正在聊天，再進行詢問或測試功能。

安裝和下載

－ Palbot (http://www.goddessfantasy.net/bbs/index.php?action=dlattach;topic=83357.0;attach=41575)

－ Freebot (http://www.goddessfantasy.net/bbs/index.php?action=dlattach;topic=83357.0;attach=41574)

下載后解壓即可直接运行。

★ 注意：很多殺毒軟體此時會報警，并自動刪除執行文件mIRC.exe或是其他擴展名為ini但這些文件是安全的，這是個常見的誤報。

請讓殺毒軟體忽略或是信任此文件。

網頁鏈接方式

目前能通過該鏈接 (https://kiwiirc.com/client/irc.ellesime.tk/?&encoding=gbk#Free)直達ＩＲＣ，但是功能不如客戶端好友並且不保留LOG。

手機／平板鏈接方式

掃碼即上，但是鏈接速度一般，與網頁鏈接的弊端一樣。

(http://www.goddessfantasy.net/bbs/index.php?action=dlattach;topic=83357.0;attach=57161;image)

如何連接到服務器

在發言區域鍵入：/server <服務器地址>:<端口>即可連接到服務器。現在唯一指定服務器為irc.ellesime.tk，注意這是個公用服務器，跑團的頻道通常以#TRPG開頭。

可以使用的服務器地址可用irc.ellesime.tk。

端口按照編碼分類：

－ GBK為6667，6668，6669。

暫無其他編碼的支持。

列出和加入頻道

在發言區域鍵入：/list可以列出全部頻道，以#TRPG為開頭的頻道通常与跑團有關。

滑鼠雙擊頻道名稱可以加入該頻道。

在發言區域鍵入：/join <頻道名>也可以加入頻道，如果頻道名不存在，你將創建一個新頻道。

使用投骰功能

當進入房間后，在發言區域鍵入：/invite dicebot #<頻道名>或是/invite oicebot #<頻道名>便可將骰子機器人邀請到你所需要的頻道中。例如/invite dicebot #新兵訓練營。

使用例如.r 1d20+1 先攻權的格式，可以讓骰子機器人進行投骰。

★ 注意：記住請勿在正在跑團的頻道中測試本功能。

IRC中到哪個頻道參與聊天和求助

請去#新兵訓練營進行求助。

如何更改文字颜色:

【Freebot】 正上方菜单栏 -> Freebot菜单 -> 色彩风格设置 -> 字符颜色

【 Palbot 】 正上方菜单栏 -> Palbot菜单 ->  系统默认色彩风格 -> 自定义前景颜色

如何做动作：

使用 /me 动作 这样的命令可以在频道里用第三人称描述的方式做出动作描述。

关闭频道管理等危险功能：

【Freebot】 正上方菜单栏 -> Freebot菜单 -> 频道管理 -> 关闭此功能

【 Palbot 】 正上方菜单栏 -> Palbot菜单 -> 自身防护设置 -> 关闭自身防护

IRC常用指令：

  • 註冊賬號

    • 指令：/ns register 密码 邮箱

    • 例子：/ns register 123456 123456@123.com

    • 注意：目前只有英文ID才能允許註冊

  • 登陸賬號

    • 指令：/ns identify 账号 密码

    • 例子：/ns identify AAAA 123456

    • 注意：无

  • 註冊頻道

    • 指令：/cs register #频道

    • 例子：/ns register #CCC

    • 注意：該頻道處於開啟狀態才能被註冊

  • 邀請骰子

    • 指令：/invite oicebot #频道

    • 例子：/invite oicebo #CCC

    • 注意：該頻道處於開啟狀態才能讓骰子進駐
